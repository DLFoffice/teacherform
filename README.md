# ระบบบันทึกงานครูต้นทาง DLTV

ระบบให้ครูต้นทางกรอก **แผนปฏิบัติงานรายบุคคล 8 คาบ/สัปดาห์** และ **ข้อเสนอการปรับปรุง “เนื้อหา/วิธีการสอน”**
ตามแบบฟอร์มของโครงการจัดการเรียนรู้ด้วยการศึกษาทางไกลผ่านดาวเทียม (DLTV) ร่วมกับโรงเรียนปลายทาง

```
┌──────────────────────────┐   fetch (POST JSON)   ┌──────────────────────────┐      ┌───────────────┐
│ หน้าเว็บ (GitHub Pages)  │ ────────────────────▶ │ Google Apps Script (API) │ ───▶ │ Google Sheets │
│ index.html / assets/     │ ◀──────────────────── │ gas/Code.gs              │      │ (ฐานข้อมูล)    │
└──────────────────────────┘                       └──────────────────────────┘      └───────────────┘
```

## โครงสร้างไฟล์
```
index.html                หน้าเว็บหลัก
assets/css/style.css      ธีม (กรมท่ามูลนิธิฯ + เหลือง DLTV) และรูปแบบหน้าพิมพ์
assets/js/config.js       ★ ตั้งค่า API_URL และ GOOGLE_CLIENT_ID
assets/js/app.js          การทำงานของหน้าเว็บ
assets/img/               โลโก้มูลนิธิฯ และ DLTV
gas/Code.gs               ★ โค้ดหลังบ้าน (วางใน Apps Script)
gas/appsscript.json       ไฟล์ manifest (ใช้กับ clasp ได้)
.github/workflows/pages.yml  deploy ขึ้น GitHub Pages อัตโนมัติ
```

---

## ขั้นที่ 1 · ติดตั้งหลังบ้าน (Google Apps Script)
1. สร้าง **Google Sheets** ใหม่ แล้วไปที่ **ส่วนขยาย → Apps Script**
2. คัดลอกโค้ดจาก `gas/Code.gs` ไปวางแทนโค้ดเดิม แล้วกดบันทึก
3. เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้** และอนุญาตสิทธิ์ ระบบจะสร้างชีต
   `แผนปฏิบัติงาน`, `ตารางปฏิบัติงาน`, `ข้อเสนอปรับปรุง`, `รายการข้อเสนอ`, `ตั้งค่า`
4. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**  ← จำเป็น เพื่อให้หน้าเว็บบน GitHub เรียกได้ (ระบบมีการตรวจสอบผู้ใช้เองในขั้นที่ 3)
5. คัดลอก **URL เว็บแอป** (ลงท้ายด้วย `/exec`) แล้วลองเปิดในเบราว์เซอร์ ต้องเห็นข้อความ `"API พร้อมใช้งาน"`

> แก้ `Code.gs` ภายหลัง: **จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** URL จะยังเป็นค่าเดิม

## ขั้นที่ 2 · ขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (หรือใช้ `git push`)
2. แก้ไฟล์ `assets/js/config.js` ใส่ `API_URL` ที่ได้จากขั้นที่ 1
3. ไปที่ **Settings → Pages → Build and deployment → Source: GitHub Actions**
4. รอ Actions ทำงานเสร็จ (ประมาณ 1 นาที) เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

> ยังไม่ใส่ `API_URL` ก็เปิดเว็บได้ ระบบจะเข้า **โหมดทดลอง** และเก็บข้อมูลไว้ในเบราว์เซอร์เท่านั้น ใช้สำหรับดูหน้าตาก่อนเชื่อมต่อหลังบ้าน

## ขั้นที่ 3 · ลงชื่อเข้าใช้ด้วย Google (แนะนำสำหรับใช้งานจริง)
หากไม่ตั้งค่าขั้นนี้ ระบบจะใช้ **โหมดง่าย** ครูกรอกชื่อและอีเมลเองโดยไม่มีการยืนยันตัวตน ใช้ทดสอบได้ แต่ไม่ปลอดภัยพอสำหรับใช้งานจริง

1. เข้า [Google Cloud Console](https://console.cloud.google.com/) → สร้างหรือเลือกโปรเจกต์
2. **APIs & Services → OAuth consent screen** ตั้งค่า (เลือก *Internal* หากใช้บัญชี Workspace ของหน่วยงาน)
3. **Credentials → Create credentials → OAuth client ID → Web application**
   - Authorized JavaScript origins: `https://<ชื่อผู้ใช้>.github.io`
4. คัดลอก **Client ID** ไปใส่ **2 ที่**:
   - `assets/js/config.js` → `GOOGLE_CLIENT_ID`
   - `gas/Code.gs` → `AUTH_CONFIG.GOOGLE_CLIENT_ID` (แล้ว deploy เวอร์ชันใหม่)
5. (ไม่บังคับ) จำกัดโดเมนได้ที่ `AUTH_CONFIG.ALLOWED_DOMAINS` เช่น `['dltv.ac.th']`
   ส่วนอีเมลนอกโดเมนให้เพิ่มในชีต “ตั้งค่า” เป็นประเภท `user`

หลังบ้านจะตรวจ ID token กับ Google ทุกครั้งที่มีการเรียก (มีแคช 10 นาที) และใช้อีเมลจาก token เป็นเจ้าของข้อมูล

## ชีต “ตั้งค่า”
| ประเภท | ค่า |
|---|---|
| `admin` | อีเมลผู้ดูแลระบบ (เห็นรายการของครูทุกคน) |
| `user` | อีเมลที่อนุญาตเพิ่มนอกโดเมนที่กำหนด |
| `school` | รายชื่อโรงเรียนปลายทาง (ขึ้นเป็นตัวเลือกให้อัตโนมัติ) |
| `subject` | รายชื่อวิชา |
| `affiliation` | รายชื่อสังกัดโรงเรียนปลายทาง เช่น สพป.ประจวบคีรีขันธ์ เขต 2 |

ชื่อโรงเรียนต้นทางและเป้าหมายจำนวนคาบแก้ได้ที่ `APP` ใน `Code.gs`

## ความสามารถ
- **แผนปฏิบัติงาน:** กรอกข้อมูลครู ห้วงเวลา และโรงเรียนปลายทาง พร้อมตารางรายวัน (วันที่ เวลา ชั้น คาบที่ ลักษณะงาน และรูปแบบที่ 1–3) มีวงแหวนนับคาบเทียบเป้าหมาย 8 คาบ
- **ข้อเสนอปรับปรุง:** กรอกเทปที่ เรื่อง ปัญหา สาเหตุ **เดิมเป็นอย่างไร → ปรับใหม่ให้เป็นอย่างไร** และนาทีที่ในเทป ดึงคาบสอนจากแผนมาเป็นรายการได้ในคลิกเดียว
- **สังกัดโรงเรียนปลายทาง:** มีตัวเลือกจากชีต “ตั้งค่า” และดึงจากแผนไปใส่ในข้อเสนอให้อัตโนมัติ
- **พิมพ์ / PDF:** ได้กระดาษ A4 แนวนอน หน้าตาเหมือนแบบฟอร์มเดิม พร้อมช่องลงชื่อ
- **ความปลอดภัยของข้อมูล:** ครูเห็นเฉพาะรายการของตัวเอง ผู้ดูแลเห็นทั้งหมด
- **ใช้บนมือถือได้:** ระบบบันทึกแบบร่างไว้ในเบราว์เซอร์ให้อัตโนมัติ

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| “เชื่อมต่อเซิร์ฟเวอร์ไม่ได้” | ตรวจว่า `API_URL` ลงท้าย `/exec` และตั้งการเข้าถึงเว็บแอปเป็น **ทุกคน** |
| ปุ่ม Google ไม่ขึ้น หรือขึ้น `origin_mismatch` | เพิ่มโดเมน `https://<user>.github.io` ใน Authorized JavaScript origins |
| “Client ID ไม่ตรงกัน” | ค่า Client ID ใน `config.js` และ `Code.gs` ต้องเหมือนกัน แล้ว deploy GAS เวอร์ชันใหม่ |
| แก้ `Code.gs` แล้วไม่มีผล | ต้อง deploy เป็น **เวอร์ชันใหม่** ทุกครั้ง |
